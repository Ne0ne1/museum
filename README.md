# Живая история ЧГУ — интерактивный стенд

Прототип музейного стенда с управлением жестами руки (без прикосновения к экрану) для музея новых технологий, экспозиция об истории ЧГУ / Чеченской Республики.

Полный план хакатона, тайминг, роли и риски — см. [`PLAN.md`](./PLAN.md). Разбивка задач на 3 человек и приоритет фич усиления — см. [`TEAM_TASKS.md`](./TEAM_TASKS.md). **Победный дизайн + железо + смета до 1.5 млн ₽** — см. [`DESIGN_PLAN.md`](./DESIGN_PLAN.md). **Трекер рук и альтернативы** — см. [`TRACKERS.md`](./TRACKERS.md).

## Быстрый запуск

Проект — чистый HTML/CSS/JS без сборщика, MediaPipe Hands подключается через CDN. Нужен только браузер (Chrome/Edge) и локальный статический сервер (нельзя открывать `index.html` напрямую через `file://` — камера и модули не заработают из-за ограничений браузера).

```bash
cd chsu-museum-stand
python3 -m http.server 8080
```

Открыть `http://localhost:8080` в Chrome, разрешить доступ к камере.

При первом запуске нужен интернет только если нет папки `vendor/mediapipe` (модель уже лежит локально в репозитории — камера должна стартовать офлайн после первой загрузки страницы с localhost).

## Управление жестами

- 🖐️ Открытая ладонь + движение влево/вправо — скроллит таймлайн.
- ☝️ Задержать указательный палец над карточкой/точкой ~0.65 сек — открывает детали (dwell-click).
- 🤏 Свести/развести большой и указательный палец в режиме карты — масштабирует карту.
- ✊ Кулак — переключение между режимами "Таймлайн" и "Карта/Галерея".

Fallback (если жест не распознался, плохое освещение и т.п.): все действия дублируются обычным кликом мыши — кнопки переключения режимов, клик по карточке/точке.

## Как заменить контент на реальный

Просто отредактировать `data/events.json` (лента времени) и `data/places.json` (карта/галерея) — поля `year`/`title`/`description`/`image`. Код менять не нужно, страница подхватит новые данные автоматически.

## Известные ограничения прототипа

- Работает с одной рукой в кадре (`maxNumHands: 1`) — осознанный выбор для стабильности на демо.
- Требует более-менее равномерного освещения — MediaPipe Hands чувствителен к контровому свету и слишком тёмным помещениям. Перед демо обязательно протестировать на месте.
- Изображения экспонатов — плейсхолдеры (`assets/placeholders/`), реальные фото нужно добавить и прописать пути в JSON.
