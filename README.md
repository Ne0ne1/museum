# Портал времени — музейный стенд

Интерактивный экран с управлением жестами руки (MediaPipe Hands): современное фото места → pinch открывает шторку сравнения с прошлым → взмах двумя руками листает места.

## Страницы

| Файл | Экран |
|---|---|
| `index.html` | Старт + подсказки жестов |
| `portal.html` | Полноэкранный портал (основной экран зала) |

Устаревшие `timeline.html` / `story-prototype.html` не используются в зале.

## Быстрый запуск (разработка)

```bash
cd museum
python3 -m http.server 8080
```

Открыть `http://localhost:8080` в Chrome, разрешить камеру.

**Нельзя** открывать через `file://` — камера и ES-модули не заработают.

MediaPipe лежит локально в `vendor/mediapipe` — после первой загрузки страницы с localhost стенд может работать офлайн.

## Управление жестами

| Жест | Действие |
|---|---|
| **Две руки ←→** | Другое место (современное фото) |
| **Pinch** | Шторка сравнения: прошлое ↔ настоящее, шов едет за рукой |
| **Кулак ~2 с** | Закрыть шторку; повторно — на стартовый экран |

Fallback без камеры: клик/drag по экрану — шторка; стрелки — места; пробел — шторка; Esc — выход.

### Отладка камеры

Превью камеры в углу **включено по умолчанию**. Скрыть в зале: `portal.html?hideCam=1`. Каркас рук рисуется всегда, пока превью видно.

### Калибровка порогов

Файл [`data/gesture-config.json`](data/gesture-config.json):

- `twohandSwipeMinPx` / `twohandSwipeMinSpeed` — чувствительность смены места
- `pinchThreshold` — щипок для шторки
- `fistHoldMs` — удержание кулака (мс)
- `idleMs` — простой → возврат на `index.html` (по умолчанию 60 с)
- `cameraRetryAttempts` / `cameraRetryDelayMs` — повтор при сбое камеры

## Контент

Новые места — только JSON (`places.json` + события в `events.json` с `placeId`). Код менять не нужно. В портал попадают места, у которых есть и «современный», и «прошлый» кадр.

## Установка в музей (камера + большой экран)

Подробные скрипты: [`scripts/kiosk/README.md`](scripts/kiosk/README.md).

Кратко:

1. ПК + Chrome + Python 3, проект на диске.
2. Камера **над экраном**, смотрит вниз на зону рук; на полу — метка «встань здесь».
3. Мягкий свет на руки (без контрового).
4. `scripts/kiosk/start-stand.bat` (Windows) или `start-stand.sh` (macOS).
5. Один раз разрешить камеру для `http://localhost:8080`.
6. Автологин ОС + ярлык в автозагрузку + отключить сон.

При фатальном сбое камеры на экране: **«Нужен сотрудник»** + текст ошибки. Стенд сам делает несколько попыток переподключения.

### Чек-лист дня монтажа

- [ ] Экран landscape, центр ~1.5–1.7 м от пола
- [ ] Камера закреплена; в `?debug=1` руки ≥25% кадра с места посетителя
- [ ] Свет как в рабочие часы зала
- [ ] Сценарий 10×: старт → pinch-шторка → две руки → кулак → старт
- [ ] Перезагрузка ПК → стенд поднимается без мыши (`start-stand`)
- [ ] Idle ~60 с возвращает на intro
- [ ] Мышь/клавиатура спрятаны у сотрудника (fallback)

### Ежедневная эксплуатация

- Утро: питание экрана/ПК (или автозапуск).
- «Нет руки»: объектив, угол камеры, свет зоны.
- Чёрный экран: жив ли Chrome? отвечает ли `localhost:8080`? видна ли камера в системе?
- Раз в неделю — перезагрузка ПК.

## Известные ограничения

- Нужны Chrome/Edge и стабильный USB/встроенный поток с камеры.
- MediaPipe чувствителен к контровому свету и тёмному залу.
- Толпа за спиной посетителя может дать ложный двуручный жест — важны угол камеры вниз и зона на полу.
