# Распределение задач на 3 человек

Базовый каркас проекта уже готов (см. `PLAN.md` и `README.md`). Ниже — что делает каждый, начиная с этой точки.

## Инструменты команды

- **GitHub** — общий репозиторий (код уже в `~/chsu-museum-stand`, git инициализирован). Создать репо на GitHub, `git remote add origin ...`, `git push`. Задачи ниже можно сразу перенести в GitHub Issues / Projects — отдельный таск-трекер не нужен.
- **Telegram/Discord (голос)** — координация в реальном времени, не переписка.
- **Google Docs** — для сборки текстов по истории ЧГУ, пока их не перенесли в JSON.

Правило: коммитить часто, маленькими кусками, чтобы не было болезненных конфликтов при трёх людях в одном репо.

## Человек 1 — Gesture/Tech Lead (трекинг руки, ядро взаимодействия)

Файлы: `js/handTracker.js`, `js/gestureState.js`

- [ ] Протестировать трекинг на реальной камере и в реальном освещении места демо
- [ ] Откалибровать пороги в `gestureState.js` (`PINCH_THRESHOLD`, `FIST_THRESHOLD`, `OPEN_PALM_THRESHOLD`, `DWELL_MS`, `CURSOR_SMOOTHING`) под конкретное расстояние человек-камера
- [ ] Добавить обработку ошибок камеры (нет доступа / несколько камер / камера занята другим приложением) с понятным сообщением на `#camera-status`
- [ ] **(усиление)** Красивый sci-fi HUD-оверлей скелета руки на весь экран (не только маленький debug-canvas в углу) — чтобы зрители на сцене видели, что происходит взаимодействие
- [ ] **(усиление, если успеваете)** Поддержка двух рук (`maxNumHands: 2`) — зум двумя руками как на интерактивном столе, эффектно для жюри
- [ ] Прогнать «стресс-тест»: разное освещение, разные люди/размеры рук, расстояние от камеры

## Человек 2 — Frontend / UI/UX

Файлы: `js/timeline.js`, `js/gallery.js`, `css/style.css`, `index.html`

**Текущий UX (уже в коде):** карта мест → выбор места → таймлайн этого места (влево = прошлое, вправо = будущее). Кулак / «← К карте» = назад.

- [ ] Полировка анимаций (переходы карточек, детальные панели, hover-состояния)
- [ ] Адаптация вёрстки под реальный экран стенда (протестировать на мониторе/проекторе, не только на ноутбуке)
- [ ] **(усиление)** Переключатель языка RU / чеченский для всех текстов интерфейса и контента — сильный аргумент для жюри, показывает культурную значимость проекта именно для ЧР
- [ ] **(усиление)** Озвучка текста карточек через Web Speech API (`speechSynthesis`) — кнопка "прослушать" на детальной панели, делает стенд более "живым" и доступным
- [ ] **(усиление, если успеваете)** Мини-квиз в конце таймлайна: 2-3 вопроса по услышанным фактам, ответ выбирается жестом (наведение на вариант) — геймификация, сильно поднимает вовлечённость и образовательную ценность
- [ ] Звуковые эффекты на действия (свайп/pinch/dwell-click) — короткие, не навязчивые

## Человек 3 — Контент, дизайн, питч

Файлы: `data/events.json`, `data/places.json`, `assets/placeholders/`

- [ ] Собрать реальные тексты и фото по истории ЧГУ (согласовать деликатные формулировки, особенно про 1990-е — проверить с музеем/руководителем)
- [ ] Заполнить `events.json` и `places.json` реальными данными (шаблон полей уже есть)
- [ ] Определить визуальный стиль: цвета/логотип ЧГУ и музея, при необходимости передать Человеку 2 для правки CSS-переменных в `:root`
- [ ] Подготовить сценарий питча (проблема → решение → живое демо → технология → масштабируемость) — черновик уже есть в `PLAN.md`, раздел 7
- [ ] Собрать 3-5 "подопытных" людей до презентации — протестировать демо на них, записать, где жест не считывается / что непонятно, передать фидбек Человеку 1 и 2
- [ ] Подготовить резервные слайды/фото на случай сбоя техники на сцене

## Приоритет фич усиления (если время ограничено)

Делать в этом порядке — каждая следующая даёт больше "wow", но и требует больше времени:

| # | Фича | Эффект на жюри | Трудозатраты |
|---|---|---|---|
| 1 | Калибровка + стабильный трекинг (must-have) | Без этого демо просто не работает | средние |
| 2 | RU/чеченский переключатель языка | Высокий — уникальность и культурная релевантность | низкие |
| 3 | Озвучка текста (TTS) | Средне-высокий — "живой" музей | низкие |
| 4 | Sci-fi HUD скелета руки на весь экран | Высокий — визуально считывается со сцены | средние |
| 5 | Звуковые эффекты на жесты | Средний — ощущение полировки | низкие |
| 6 | Мини-квиз (геймификация) | Высокий — образовательная ценность + вовлечение | средние |
| 7 | Две руки / zoom двумя руками | Высокий, но рискованно по времени | высокие |

Рекомендация: если что-то не успеваете — жертвуйте пунктом 7 первым, он самый дорогой и наименее критичный.
