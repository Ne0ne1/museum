# Какой трекер рук используем и есть ли лучше

## Что сейчас в проекте

**MediaPipe Hands (Google)** через CDN в браузере.

- 21 точка на кисть
- работает в Chrome с обычной веб-камерой
- бесплатно, без спецжелеза
- уже подключено в `map.html` / `timeline.html`

Для хакатона и музейного стенда это **лучший старт**: быстро, стабильно, легко показывать жюри.

---

## Сравнение альтернатив

| Трекер | Где работает | Плюсы | Минусы | Для нас |
|---|---|---|---|---|
| **MediaPipe Hands** ← сейчас | Браузер / Python | Бесплатно, 21 landmark, CDN, много туториалов | Чувствителен к свету; 1–2 руки | **Оставить** |
| **MediaPipe Gesture Recognizer** (Tasks Vision) | Браузер | Готовые жесты (открытая ладонь, кулак, victory…) | Другой API, чуть дольше внедрить | Можно апгрейднуть позже |
| **TensorFlow.js HandPose** | Браузер | Похож на MediaPipe | Обычно тяжелее/медленнее | Не лучше |
| **OpenCV + кастомная модель** | Python | Полный контроль | Долго писать, сложнее на стенде | Не для 24ч |
| **Leap Motion / Ultraleap** | Спец. сенсор | Очень точный трекинг пальцев | Железо + драйверы + бюджет + риск на демо | Только если купите сенсор и будет время |
| **Azure Kinect / RealSense** | ПК + depth-камера | Глубина, скелет | Дорого, сложно, overkill | Не нужно |
| **Apple Vision / ARKit** | только Apple | Качество на iPad | Не кроссплатформенно для музейного ПК | Нет |
| **Ultralytics YOLO hand** | Python/GPU | Детекция руки | Нет точных 21 точек «из коробки» для жестов | Слабее для UI-курсора |

### Вывод

1. **Сейчас и на защиту:** MediaPipe Hands — правильный выбор.  
2. **Если успеете усилить:** перейти на **MediaPipe Tasks Gesture Recognizer** (лучше «кулак / открытая ладонь» из коробки).  
3. **Если бюджет и время на железо:** Ultraleap — заметный wow, но это отдельный риск и интеграция.  
4. **Не менять трекер ради «другого названия»** — жюри важнее стабильный демо, чем бренд SDK.

Критичнее трекера: **свет + камера 4K + калибровка порогов** в `gestureState.js`.
