# Автозапуск музейного стенда

Скрипты в этой папке поднимают локальный сервер и Chrome в киоске.

## Один раз перед открытием зала

1. Скопируйте проект на ПК стенда (путь без пробелов предпочтителен).
2. Установите **Python 3** и **Google Chrome** (или Edge).
3. Запустите сервер: `start-server.bat` / `start-server.sh`.
4. Откройте в Chrome `http://localhost:8080` → разрешите **камеру навсегда** для этого сайта.
5. Проверьте жесты на `http://localhost:8080/portal.html?debug=1` (видно превью камеры).
6. Закройте обычный Chrome и дальше используйте только kiosk-скрипты.

## Ежедневный запуск

| ОС | Команда |
|---|---|
| Windows | двойной клик `start-stand.bat` |
| macOS | `chmod +x scripts/kiosk/*.sh` затем `./scripts/kiosk/start-stand.sh` |

### Windows — автологин и старт с Windows

1. Параметры → Учётные записи → Параметры входа → отключить PIN-запрос при желании / настроить автологин через `netplwiz`.
2. Параметры → Система → Питание → никогда не уходить в сон / гибернацию при питании от сети.
3. `Win+R` → `shell:startup` → ярлык на `start-stand.bat`.
4. Либо Планировщик заданий: триггер «При входе в систему», действие — `start-stand.bat`.

### macOS — объекты входа

1. Системные настройки → Основные → Объекты входа → добавить `start-stand.sh`.
2. Отключить автоматический сон и заставку для этого пользователя.
3. В Chrome-профиле киоска камера уже должна быть разрешена (см. выше).

## Отладка на месте

- Превью камеры: `http://localhost:8080/portal.html?debug=1`
- Пороги жестов: [`data/gesture-config.json`](../../data/gesture-config.json)
- Idle-сброс на intro: поле `idleMs` (по умолчанию 60000)

## Важно

- Не открывать `index.html` через `file://` — камера не заработает.
- Не чистить профиль `%LOCALAPPDATA%\museum-kiosk-chrome` / `~/Library/Application Support/museum-kiosk-chrome` без нужды — там разрешение камеры.
- Отложите автообновление Chrome на стенде или проверяйте стенд после крупных обновлений.
